## 3.3 How the tools worked together

| Activity | Tool |
|---|---|
| Requirements and tasks | Trello cards, each linked to an SRS requirement ID |
| Discussion and decisions | Discord channels and meetings |
| Code, reviews and history | Git and GitHub (branches, commits, pull requests) |
| Automated checks | GitHub Actions: lint and all test suites on every push |
