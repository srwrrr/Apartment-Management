# Usability test kit

This test checks NFR-08 (simple enough for users with low technical skill) and NFR-09 (a new resident finds their balance and submits a maintenance request within 3 minutes, without help). It has to be done with real people, and it has not been run yet.

## Who to test with

At least 3 people who did not build the system. Try to include someone older or less used to smartphones, and someone who prefers Bangla. Each session takes about 20 minutes.

## Before each session

1. Run the system and create a fresh resident account for the person. Add one unit, one unpaid bill and one announcement for them.
2. Use a phone if you can, because most residents will.
3. Have a timer and a copy of the results table below.

## What to say

> We are testing the app, not you. If something is hard, that is the app's fault, and it helps us to see it. Please say out loud what you are thinking. I can't help you during a task, but you can stop any time. We won't record your name in our results.

Then give them the login details and read each task aloud. Don't point at the screen or hint. If someone is stuck for 2 minutes, mark the task as failed and move on.

## Tasks

| # | Task to read aloud | Done when | Target |
|---|---|---|---|
| 1 | "Log in. Find out how much money you owe." | They say the amount | Tasks 1 and 2 together within 3 minutes (NFR-09) |
| 2 | "Your kitchen tap is leaking. Tell the building office." | The request is submitted | |
| 3 | "You paid this bill with bKash. Tell the office, using transaction ID ABC123." | The report is sent | 3 minutes |
| 4 | "Is there any news from the building? What does it say?" | They read the announcement | 1 minute |
| 5 | "Change the app to Bangla, and make the text bigger." | Both are done | 1 minute |
| 6 | "You need a record of your account for this year, as a PDF." | The PDF opens | 2 minutes |

For an office staff member, also try:

| # | Task to read aloud | Done when | Target |
|---|---|---|---|
| 7 | "A resident says they paid. Check the report and accept it." | The report is verified | 2 minutes |
| 8 | "Tell everyone on floor 2 that the water will be off on Friday." | The announcement is published | 3 minutes |

## Afterwards

Ask each person:

1. What was the hardest part?
2. Was anything confusing or worded strangely? (Ask about the Bangla too.)
3. On a scale of 1 to 5, how easy was it to use?

## Results

Fill in one row for each person and task.

| Person (A, B, C) | Task | Finished without help? | Time | What went wrong |
|---|---|---|---|---|
| | | | | |

The test passes if every person finishes tasks 1 and 2 within 3 minutes without help, and most of the other tasks without help. Fix anything that stopped more than one person, then test those tasks again.
